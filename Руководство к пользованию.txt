1. ЧТО ТАКОЕ ConSecOrg
══════════════════════════════════════════════════════════════════════════════

ConSecOrg (Confidential Secure Organizer) — защищённый электронный органайзер
для хранения деловых заметок, задач и контактов. Все ваши данные шифруются
по российскому стандарту ГОСТ Р 34.12-2015 («Кузнечик»). Это значит, что
даже если кто-то получит файл базы данных с вашего компьютера, прочитать
содержимое без вашего пароля или PIN-кода будет невозможно.

Программа работает в двух режимах:

  ┌─────────────────────────────────────────────────────────────┐
  │  ПЕРСОНАЛЬНЫЙ РЕЖИМ                                         │
  │  Только для вас. Данные хранятся на вашем компьютере.       │
  │  Интернет и сервер не нужны.                                │
  └─────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────┐
  │  КОРПОРАТИВНЫЙ РЕЖИМ                                        │
  │  Для организаций. Данные хранятся на корпоративном сервере. │
  │  Есть роли, аудит, совместная работа.                       │
  └─────────────────────────────────────────────────────────────┘


══════════════════════════════════════════════════════════════════════════════
2. СИСТЕМНЫЕ ТРЕБОВАНИЯ
══════════════════════════════════════════════════════════════════════════════

Операционная система:   Windows 10 (версия 1809 и выше) или Windows 11
Оперативная память:     не менее 4 ГБ ОЗУ
Место на диске:         не менее 200 МБ свободного пространства
Сеть (только корп.):    доступ к корпоративному серверу ConSecOrg

Программа НЕ требует подключения к интернету в персональном режиме.

3. ПЕРВЫЙ ЗАПУСК — ВЫБОР РЕЖИМА РАБОТЫ
══════════════════════════════════════════════════════════════════════════════

При первом запуске программа показывает экран выбора режима. Вы увидите
две большие карточки:

  ┌──────────────────────┐   ┌──────────────────────┐
  │  🔒 ПЕРСОНАЛЬНЫЙ     │   │  🌐 КОРПОРАТИВНЫЙ    │
  │                      │   │                      │
  │  Локальное хранение  │   │  Подключиться к      │
  │  Без сервера         │   │  серверу организации │
  └──────────────────────┘   └──────────────────────┘

Нажмите на нужную карточку. Выбор режима можно изменить при следующем запуске.

ВАЖНО: Данные персонального и корпоративного режимов хранятся отдельно
и не пересекаются между собой.

4.1 СОЗДАНИЕ И ВХОД ПО PIN-КОДУ
──────────────────────────────────────────────────────────────────────────────

ПЕРВЫЙ ЗАПУСК (создание PIN-кода):
  1. Программа попросит вас придумать PIN-код (минимум 4 символа).
     Можно использовать цифры и буквы.
  2. Введите PIN-код и подтвердите его повторным вводом.
  3. Нажмите «Создать».

  ⚠️  ВАЖНО: PIN-код нигде не хранится в явном виде. Если вы его забудете —
  восстановить данные будет невозможно. Запишите PIN-код в надёжное место.

ПОСЛЕДУЮЩИЕ ЗАПУСКИ (вход):
  1. Введите ваш PIN-код в поле ввода.
  2. Нажмите «Войти» или клавишу Enter.
  3. После 5 неверных попыток ввода PIN-код блокируется на 1 минуту.

──────────────────────────────────────────────────────────────────────────────
4.2 ЗАМЕТКИ (персональный режим)
──────────────────────────────────────────────────────────────────────────────

Раздел «Заметки» открывается кнопкой в боковом меню слева.

СОЗДАНИЕ ЗАМЕТКИ:
  1. Нажмите кнопку «+ Новая заметка» (или «+» в верхнем правом углу).
  2. Введите заголовок заметки.
  3. Напишите текст в левой панели редактора. Поддерживается форматирование
     Markdown (см. шпаргалку ниже).
  4. В правой панели сразу виден отформатированный результат.
  5. Выберите уровень безопасности (подробнее — в разделе 6).
  6. Нажмите «Сохранить» (Ctrl+S).

РЕДАКТИРОВАНИЕ ЗАМЕТКИ:
  1. Нажмите на карточку заметки в списке слева.
  2. Редактор откроется справа. Вносите изменения.
  3. Сохранение — автоматически при переходе на другую заметку,
     либо вручную Ctrl+S.

УДАЛЕНИЕ ЗАМЕТКИ:
  1. Нажмите правой кнопкой мыши на карточку заметки.
  2. Выберите «Удалить».
  3. Подтвердите удаление.

  Обычное удаление: запись помечается как удалённая.
  Надёжное удаление: данные перезаписываются случайными байтами перед
  удалением — восстановление невозможно (см. раздел 7 — Таймер уничтожения).

ПОИСК И ФИЛЬТРАЦИЯ:
  • Строка поиска в верхней части списка — поиск по тексту.
  • Кнопки фильтра: «Все», «Публичные», «Внутренние», «Конфиденциальные»,
    «Секретные».
  • Кнопка «С таймером» — показывает только заметки с таймером уничтожения.

ВИД СПИСКА:
  • Кнопка-переключатель в верхнем правом углу списка меняет вид:
    - Карточки (большие плитки с превью текста)
    - Компактный список (строки)

ШПАРГАЛКА ПО MARKDOWN:
  **жирный**           → жирный текст
  *курсив*             → курсивный текст
  # Заголовок 1        → большой заголовок
  ## Заголовок 2       → заголовок поменьше
  - элемент списка     → маркированный список
  1. элемент           → нумерованный список
  `код`                → строка кода
  ---                  → горизонтальная линия

4.3 ЗАДАЧИ И КАНБАН-ДОСКА (персональный режим)
──────────────────────────────────────────────────────────────────────────────

Раздел «Задачи» открывается кнопкой в боковом меню.

ЧТО ТАКОЕ КАНБАН-ДОСКА:
  Канбан — визуальная доска с колонками по статусу задачи. Задачи
  перетаскиваются из колонки в колонку по мере выполнения.

  По умолчанию 4 колонки:
  [ К выполнению ] → [ В работе ] → [ На проверке ] → [ Готово ]

СОЗДАНИЕ ПРОЕКТА:
  1. Нажмите «+ Новый проект» в боковой панели.
  2. Введите название проекта.

СОЗДАНИЕ ЗАДАЧИ:
  1. Нажмите «+» в нижней части нужной колонки, либо кнопку «+ Задача».
  2. Введите название задачи.
  3. При необходимости нажмите на карточку задачи и заполните:
     - Описание (поддерживает Markdown)
     - Приоритет: Низкий / Нормальный / Высокий / Критический
     - Срок выполнения (дедлайн)
     - Теги
     - Подзадачи (чек-лист)

ПЕРЕМЕЩЕНИЕ ЗАДАЧИ:
  1. Зажмите левую кнопку мыши на карточке задачи.
  2. Перетащите её в другую колонку.
  3. Отпустите кнопку мыши.

ЦВЕТ И НАСТРОЙКА КОЛОНОК:
  1. Нажмите кнопку «⋮» (три точки) в заголовке колонки.
  2. Доступные действия:
     - Переименовать колонку
     - Выбрать цвет (12 цветов)
     - Удалить колонку
     - Сортировать задачи

  ⚠️  При удалении колонки все задачи в ней также удаляются.

ПРИОРИТЕТЫ — ЦВЕТОВАЯ ИНДИКАЦИЯ:
  🟢 Зелёный  — Низкий
  🔵 Синий    — Нормальный
  🟠 Оранжевый — Высокий
  🔴 Красный  — Критический

  Просроченные задачи (дедлайн прошёл) выделяются красным фоном.

──────────────────────────────────────────────────────────────────────────────
4.4 КАЛЕНДАРЬ (персональный режим)
──────────────────────────────────────────────────────────────────────────────

Раздел «Календарь» показывает ваши задачи и заметки в привязке к датам.

ПЕРЕКЛЮЧЕНИЕ ВИДА:
  • Кнопки «Месяц» / «Неделя» в верхней части экрана.

МЕСЯЧНЫЙ ВИД:
  - Сегодняшняя дата подсвечена акцентным цветом.
  - Выходные дни выделены.
  - На каждом дне видны точки-индикаторы: количество заметок и задач.
  - Нажмите на любой день — откроется боковая панель со списком
    задач и заметок этого дня.
  - В боковой панели можно создать новую задачу или заметку прямо
    из календаря — дата заполнится автоматически.

НЕДЕЛЬНЫЙ ВИД:
  - Отображает текущую неделю.
  - Кнопки «←» и «→» переключают недели.

──────────────────────────────────────────────────────────────────────────────
4.5 НАСТРОЙКИ (персональный режим)
──────────────────────────────────────────────────────────────────────────────

Раздел «Настройки» открывается в нижней части бокового меню (иконка шестерёнки).

ВНЕШНИЙ ВИД:
  - Тема: Тёмная / Светлая
  - Акцентный цвет: 16 предустановленных цветов + произвольный HEX-код
  - Размер шрифта: от 12 до 20
  - Фоновое изображение рабочего пространства

СМЕНА PIN-КОДА:
  1. Вкладка «Безопасность».
  2. Введите текущий PIN-код.
  3. Введите новый PIN-код и подтвердите его.
  4. Нажмите «Сохранить».

──────────────────────────────────────────────────────────────────────────────
4.6 ИКОНКА В ТРЕЕ (персональный режим)
──────────────────────────────────────────────────────────────────────────────

При закрытии окна программа сворачивается в системный трей (область уведомлений
Windows, правый нижний угол экрана).

Действия через иконку в трее:
  • Двойной клик — открыть окно программы
  • Правый клик — контекстное меню:
    - «Открыть» — показать окно
    - «Выйти» — полностью закрыть программу

Уведомления в трее:
  - За 30 минут до уничтожения заметки по таймеру: предупреждение
  - За 5 минут до уничтожения: критическое предупреждение
  - После уничтожения: «Заметка "[название]" надёжно уничтожена»

──────────────────────────────────────────────────────────────────────────────
5.1 ПОДКЛЮЧЕНИЕ К СЕРВЕРУ
──────────────────────────────────────────────────────────────────────────────

На экране выбора режима нажмите «Корпоративный». Откроется форма подключения:

  1. Введите адрес сервера (выдаётся системным администратором).
     Пример: https://consec.company.ru
  2. Нажмите «Подключиться».
  3. Программа проверит доступность сервера.
  4. Если сервер доступен — откроется форма входа.

  ❓ Адрес сервера не знаете? Обратитесь к системному администратору.

  Контакты (создать/ред./удал.)     │      ✅       │  ✅ *    │   ❌    │  ✅
  Просмотр журнала аудита           │      ❌       │    ❌    │   ✅    │  ✅
  Проверка целостности аудита       │      ❌       │    ❌    │   ✅    │  ✅

5.3 РЕГИСТРАЦИЯ И ВХОД
──────────────────────────────────────────────────────────────────────────────

ПЕРВЫЙ ВХОД В СИСТЕМУ (только Администратор):
  Системный администратор выполняет первичную настройку через специальный
  одноразовый адрес /auth/bootstrap. После этого он создаёт учётные записи
  для остальных сотрудников.

ВХОД ДЛЯ СОТРУДНИКОВ:
  1. Введите имя пользователя (логин) — выдаётся администратором.
  2. Введите пароль — выдаётся администратором при первом входе.
  3. Нажмите «Войти».

ПЕРВЫЙ ВХОД — ОБЯЗАТЕЛЬНАЯ СМЕНА ПАРОЛЯ:
  При первом входе система потребует сменить временный пароль на постоянный.
  Требования к паролю:
  - Минимум 12 символов
  - Рекомендуется использовать буквы, цифры и специальные символы

БЛОКИРОВКА УЧЁТНОЙ ЗАПИСИ:
  После 5 неверных попыток ввода пароля учётная запись блокируется.
  Разблокировать её может только Администратор.

ПРИВЯЗКА К УСТРОЙСТВУ:
  При первом входе система запоминает ваш компьютер (по аппаратным
  идентификаторам). При последующих входах с другого устройства — в доступе
  будет отказано. Если вам нужно войти с нового компьютера — обратитесь к
  Администратору для сброса привязки.

АВТОМАТИЧЕСКИЙ ВЫХОД:
  Если вы не совершаете никаких действий в течение 30 минут — сессия
  автоматически завершается и программа возвращается на экран входа.
  Несохранённые данные сохраняются автоматически перед выходом.

5.11 ЖУРНАЛ АУДИТА (только Аудитор и Администратор)
──────────────────────────────────────────────────────────────────────────────

ЧТО ЗАПИСЫВАЕТСЯ В ЖУРНАЛ:
  Система автоматически фиксирует каждое значимое действие:
  • Входы и выходы из системы
  • Создание, чтение (для уровней Конфиденциальный и Секретный), изменение
    и удаление заметок, задач, контактов
  • Блокировку учётных записей
  • Попытки несанкционированного доступа
  • Изменение ролей пользователей
  • Надёжное уничтожение записей

ПРОСМОТР ЖУРНАЛА:
  1. Откройте раздел «Аудит» в боковом меню.
  2. Таблица журнала показывает: дату, время, пользователя, действие,
     IP-адрес и статус.
  3. Используйте фильтры вверху:
     - Период (дата «от» и «до»)
     - Конкретный пользователь
     - Тип события
  4. Навигация по страницам — кнопки «←» и «→» внизу таблицы.

ПРОВЕРКА ЦЕЛОСТНОСТИ ЖУРНАЛА:
  Нажмите кнопку «Проверить целостность» в верхней части раздела «Аудит».

  Результат:
  ✅  Зелёный баннер «Цепочка не нарушена» — журнал не был подделан.
  ❌  Красный баннер «Обнаружено вмешательство в запись #N» — в записи
      с указанным номером было обнаружено несанкционированное изменение.
      Немедленно сообщите об этом руководству.

ЭКСПОРТ ЖУРНАЛА:
  1. Настройте фильтры (период, пользователь).
  2. Нажмите «Экспортировать в CSV».
  3. Выберите папку для сохранения файла.
  4. Файл CSV откроется в Excel или любой другой программе для таблиц.

7. ТАЙМЕР УНИЧТОЖЕНИЯ ЗАПИСЕЙ
══════════════════════════════════════════════════════════════════════════════

Таймер уничтожения позволяет установить дату и время, по наступлении которых
заметка будет автоматически и безвозвратно удалена.

ЗАЧЕМ ЭТО НУЖНО:
  Некоторые данные актуальны только ограниченное время: одноразовые пароли,
  черновики предложений, данные текущих переговоров. По истечении срока
  актуальности такие данные становятся источником риска.

КАК УСТАНОВИТЬ ТАЙМЕР:
  1. Откройте заметку в редакторе.
  2. В верхней панели инструментов нажмите на иконку часов 🕐.
  3. Выберите дату уничтожения в календаре.
  4. Введите время (часы:минуты).
  5. Нажмите «Установить».
  6. На карточке заметки появится виджет обратного отсчёта.

ВИДЖЕТ ОБРАТНОГО ОТСЧЁТА:
  На карточке заметки с таймером отображается круговой индикатор:
  • 🟢 Зелёный — времени достаточно
  • 🟠 Оранжевый — осталось меньше 1 часа
  • 🔴 Красный — осталось меньше 5 минут

УВЕДОМЛЕНИЯ:
  • За 30 минут — предупреждение в трее и всплывающее окно
  • За 5 минут — критическое предупреждение
  • После уничтожения — уведомление «Заметка "[название]" надёжно уничтожена»

КАК РАБОТАЕТ «НАДЁЖНОЕ УНИЧТОЖЕНИЕ»:
  Обычное удаление файла оставляет данные на диске (их можно восстановить
  специальными программами). Надёжное уничтожение сначала перезаписывает
  место хранения данных случайными байтами, и только потом удаляет запись.
  Восстановление таких данных технически невозможно.

ОТМЕНА ТАЙМЕРА:
  1. Откройте заметку.
  2. Нажмите на иконку часов 🕐.
  3. Нажмите «Отменить таймер».

  ⚠️  После наступления времени уничтожения отменить процесс нельзя.


══════════════════════════════════════════════════════════════════════════════
8. СМЕНА ТЕМЫ И ВНЕШНЕГО ВИДА
══════════════════════════════════════════════════════════════════════════════

БЫСТРОЕ ПЕРЕКЛЮЧЕНИЕ ТЕМЫ:
  В правом верхнем углу главного окна — кнопка с иконкой луны/солнца.
  Нажмите её для переключения между тёмной и светлой темой.

НАСТРОЙКА АКЦЕНТНОГО ЦВЕТА:
  1. Откройте «Настройки» → вкладка «Внешний вид».
  2. Выберите цвет из 16 предустановленных.
  3. Или введите произвольный HEX-код (например: #FF5722).
  4. Интерфейс обновится мгновенно — перезапуск не нужен.

ФОНОВОЕ ИЗОБРАЖЕНИЕ:
  1. «Настройки» → «Внешний вид» → «Фоновое изображение».
  2. Нажмите «Выбрать файл» и укажите изображение (JPG, PNG).
  3. Нажмите «Применить».

РАЗМЕР ШРИФТА:
  Ползунок «Размер шрифта» — от 12 до 20 пунктов.
  Изменение применяется ко всему тексту интерфейса.


══════════════════════════════════════════════════════════════════════════════
9. БЕЗОПАСНОСТЬ: ЧТО ПРОГРАММА ДЕЛАЕТ ДЛЯ ЗАЩИТЫ ВАШИХ ДАННЫХ
══════════════════════════════════════════════════════════════════════════════

Этот раздел объясняет, как именно программа защищает ваши данные, без
технических подробностей.

ШИФРОВАНИЕ ДАННЫХ:
  Все ваши заметки, задачи и контакты хранятся в зашифрованном виде по
  российскому стандарту ГОСТ Р 34.12-2015 («Кузнечик»). Это значит:
  • Данные на диске — набор случайных байт без ключа.
  • Даже администратор сервера не может прочитать ваши записи.
  • Если жёсткий диск украдут — данные останутся нечитаемыми.

ЗАЩИТА ПАРОЛЯ:
  Ваш пароль нигде не хранится. Хранится только математическое
  «доказательство» знания пароля. Подобрать пароль по этому доказательству
  в разумные сроки невозможно.

КОНТРОЛЬ ЦЕЛОСТНОСТИ:
  Каждая запись снабжена «цифровой подписью». Если кто-то попытается
  изменить данные напрямую в базе данных (в обход программы), система
  обнаружит это и откажется показывать запись.

ПРИВЯЗКА К УСТРОЙСТВУ (корпоративный режим):
  Система запоминает «отпечаток» вашего компьютера. Даже если злоумышленник
  узнает ваш пароль — войти с чужого компьютера не получится.

ЗАЩИЩЁННЫЙ ЖУРНАЛ АУДИТА:
  Все действия в системе записываются в журнал, который нельзя подделать
  незаметно. Каждая запись журнала математически связана с предыдущей.
  Любое изменение журнала будет обнаружено при проверке.

НАДЁЖНОЕ УНИЧТОЖЕНИЕ:
  При удалении через таймер данные не просто «удаляются», а перезаписываются
  случайными байтами. Восстановление такой записи невозможно.

ЧТО ДЕЛАТЬ ПРИ ПОДОЗРЕНИИ НА ВЗЛОМ:
  1. Немедленно завершите все активные сессии («Безопасность» →
     «Отозвать все остальные сессии»).
  2. Смените пароль («Настройки» → «Безопасность» → «Сменить пароль»).
  3. Сообщите системному администратору.


══════════════════════════════════════════════════════════════════════════════
10. ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ
══════════════════════════════════════════════════════════════════════════════

В: Я забыл PIN-код. Как восстановить доступ к данным?
О: К сожалению, восстановить доступ невозможно. PIN-код используется для
   шифрования данных, и без него расшифровать их нельзя — это принципиальное
   решение в пользу безопасности. Рекомендуем хранить PIN-код в надёжном месте.
   После сброса (переустановки) программы можно начать работу заново.

В: Я забыл пароль от корпоративного аккаунта.
О: Обратитесь к системному администратору. Он сбросит пароль и выдаст
   временный. Ваши данные сохранятся.

В: Почему меня не пускает с нового компьютера?
О: В корпоративном режиме система запоминает ваш компьютер при первом входе.
   Если вам нужно войти с другого устройства, обратитесь к администратору
   для сброса привязки устройства.

В: Могу ли я восстановить заметку, которую уничтожил таймер?
О: Нет. Надёжное уничтожение необратимо. Данные перезаписываются случайными
   байтами до удаления.

В: Программа закрылась, но я не нашёл её на панели задач.
О: Программа свёрнута в трей. Посмотрите в правый нижний угол экрана
   (область уведомлений Windows, иконка рядом с часами).

В: Как добавить коллегу в совместный проект?
О: Создайте проект, скопируйте код приглашения (4-7 символов) и отправьте
   его коллеге. Коллега вводит этот код в разделе «Совместные проекты» →
   «+ Присоединиться».

В: Почему заметки с уровнем «Конфиденциальный» видит Аудитор?
О: Аудитор по своей роли обязан контролировать все данные в системе.
   Его доступ только для чтения и фиксируется в журнале аудита.

В: Как изменить тему без перезапуска?
О: Нажмите иконку луны/солнца в правом верхнем углу. Тема меняется мгновенно.

В: Сколько задач можно создать?
О: Ограничений на количество задач и заметок нет.

В: Программа не запускается. Что делать?
О: Убедитесь, что на компьютере установлена Microsoft SQL Server LocalDB
   (для персонального режима). Для корпоративного режима — проверьте
   подключение к сети. Если проблема сохраняется — обратитесь к
   системному администратору.

11. СООБЩЕНИЕ ОБ ОШИБКАХ
══════════════════════════════════════════════════════════════════════════════

Если программа работает некорректно:

  1. Запишите, что именно происходит (какое действие, что написано на экране).
  2. Сделайте снимок экрана (Win+Shift+S или PrintScreen).
  3. Журнал ошибок находится по пути:
       C:\Users\[ВашеИмя]\AppData\Roaming\ConSecOrg\crash.log
     (чтобы открыть папку AppData: нажмите Win+R, введите %AppData%)
  4. Сообщите об ошибке системному администратору или разработчику.

  ⚠️  Не передавайте файл базы данных (*.mdf) третьим лицам. Несмотря на
  шифрование, это является нарушением режима конфиденциальности.
